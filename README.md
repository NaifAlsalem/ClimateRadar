# Climate Radar — Strategic Intelligence Platform

A browser-based strategic intelligence dashboard for monitoring, analyzing, 
and reporting on global climate negotiation signals in real time.

## Purpose
Climate Radar continuously scans key international climate sources — IPCC, 
UNFCCC, IEA, G7, AU, and more — to surface risks, narrative shifts, and 
strategic opportunities relevant to the Arab Group and Saudi negotiating 
positions.

## Features
-  Live radar display with risk-level blips (High / Medium / Low)
-  Keyword Watch where it tracks any climate term across all signals
-  Automatic link verification for every source
-  One-click PDF export with full signal details
-  Manual re-scan simulation with animated sweep
-  Narrative Shift Index tracking key language trends

## Deployment
Single-file HTML — no build step, no dependencies to install.  
Open "climate-radar.html" directly in any modern browser.
